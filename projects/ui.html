The Interface

屏幕，
是反思通道，
不是仪表盘

动作进行中，任何视觉信息都不应是必要的。In-action 反馈走力、触觉、声音；屏幕只在组间休息、训练总结、阶段切换与安全事件时出现——让注意力回到身体。React Native 实现。

Eyes-free Paradigm

把注意力还给身体

术后早期患者因频繁看屏幕而忽略本体感觉，反而延缓恢复。Eyes-free 不只是 UX 选择，而是一种康复手段。

务实 Eyes-free
日常使用版
手机移开，手表保留最小可瞥视状态。第一版原型实现这一流派，平衡安全感与专注。
严格 Eyes-free
研究探针的纯净版
手表关、手机移开，所有训练中反馈走力反馈 / 声音 / 触觉。作为未来工作与实验条件。
App Screens

四个关键界面

围绕三阶段框架组织信息架构：让用户知道自己在哪个阶段、目标与限制是什么、为什么进阶或调整。

首页 · 阶段状态
计划 · 阶段管理
训练 · 实时反馈
模态 · 安全事件
Reflection, not realtime

语言只在反思窗口出现

训练执行界面提供「可瞥视状态」，但不依赖它。屏幕上的文字遵守具体、有数据锚、有路径三原则——不安慰、不夸赞、不用感叹号与 emoji。组间休息与总结时，才回到屏幕回看这一组发生了什么。

Design System

一套克制的视觉语言

Tone
非命令、非表演
语言具体、有数据锚、有路径；没有感叹号、emoji 或拟人化称谓。
Density
随阶段递减
早期信息密集、引导强；后期界面淡出，把控制权交还用户。
Hierarchy
卡片化阶段叙事
以 episode 而非仪表盘讲述进展，让用户理解「为什么」。
